# Audio credits

Every recording here is CC0 (public domain dedication). No attribution is required, but the sources are listed so they can be checked and replaced. Each file was trimmed, mixed to mono, resampled to 24 kHz or 22.05 kHz, normalized and encoded as 48 kbps MP3. Loops have their tail crossfaded into the head so they repeat seamlessly.

If a file fails to load, `src/audio.js` falls back to the procedural sound.
